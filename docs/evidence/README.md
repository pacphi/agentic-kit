# Evidence records

Evidence is valid for its named source, artifact, version, time, environment and test method.
A saved digest or successful fixture does not establish current runtime health, all-host parity,
production readiness or authorization to release. Source receipts and their original hashes are
retained; this documentation audit does not rewrite or re-sign them against a newer checkout.

| Record | Scope and limits |
| --- | --- |
| [Claude timeout conformance](claude-2.1.266-hook-timeouts.md) | Exact macOS executable digest and bounded extracted functions; not an end-to-end paid session or all-version hook proof |
| [Codex context conformance](codex-context-0.153.4.md) | Exact client profile, model allocations and synthetic sessions; not full-window processing, universal entitlement or API/host-window equivalence |
| [AQE source receipt](aqe-repair-source-receipt-2026-09-09.json) | Source/validation inputs named by the receipt; no broader release authority |
| [Ruflo cross-host audit](ruflo-cross-host-audit-2026-09-09.json) | Dated local/package observations with recorded gaps; later runtime state must be inspected again |
| [Dashboard fixture captures](dashboard-project-context/README.md) | September 9 PR #210 synthetic HTTP fixtures, viewport and interaction evidence; not private project data or a fresh full accessibility audit |

Opt-in conformance commands may run real host processes or inference. Their presence in a report is
not a request to run them. Preserve the exact declared probe scope and obtain the task's authority
before executing them. Ordinary documentation review can inspect the record without re-running it.
