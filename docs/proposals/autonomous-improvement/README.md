# Autonomous Improvement Documentation

These documents describe two related but separate product paths. Both remain proposed until their ADR and implementation gates are accepted.

| Docset | Purpose | Documents |
| --- | --- | --- |
| Agentic-kit self-laboratory | Improve agentic-kit through a bounded external laboratory and graduate verified proposals through protected GitHub review | [Research](ruvnet-evolution-adoption.md), [implementation plan](implementation-plan.md), [contracts](contracts.md), [foundation](foundation.md), [learning and operations](learning-and-operations.md), [graduation research](graduation-and-actions.md) |
| Project autonomous companion | Let an explicit project setup profile generate a project-owned, initially inactive laboratory companion | [Research](project-companion-research.md), [design](project-companion-design.md), [foundation plan](project-companion-foundation-plan.md), [operations plan](project-companion-operations-plan.md) |

The self-laboratory has authority only over its own experimental state. A project companion has authority only over its own generated templates and owner-approved laboratory state. Neither path merges source, changes project configuration, creates GitHub administration settings, or releases artifacts without a separate authorized protected-mainline process.
