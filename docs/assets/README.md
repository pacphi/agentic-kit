# Documentation illustrations

These assets explain behavior or preserve a design mock. They are not observations of the reader's
machine, release receipts, or current dashboard screenshots.

| Assets | Intended reading |
| --- | --- |
| [About mock](about-tab-mock.html), [System mock](system-tab-mock.html) | Historical design examples for ADR-0026/0025. Fixture labels, counts, tabs and styling are illustrative; current UI is generated by `src/lib/dashboard/page.mjs` and client modules. |
| [Transcript pipeline](transcript-pipeline.svg) | Current simplified acquisition diagram: guarded JSONL path plus a separate read-only SQLite branch. The JSONL whole-file cap does not apply to SQLite materialization. |
| [Read paths](transcript-read-paths.svg) | JSONL scan/reader distinction; OpenCode's SQLite adapter is additional. Intermediate parsing is transient; cached records exclude full turn bodies. |
| [Turn attribution](transcript-turn-attribution.svg) | Claude classification cascade, separate Codex provenance gate, and one historical measured sample. Turn kind is not proof of human authorship; sample proportions are not current corpus statistics. |
| [Masking/truncation](transcript-mask-truncate.svg) | Best-effort recognized-secret masking before the per-turn length cap. It is not proof that all possible secrets are removed. |
| [Token accounting](usage-token-accounting.svg) | Illustrative Claude deltas versus Codex cumulative totals, not historical pressure or a cross-host bill. OpenCode accounting is a separate adapter. |
| [Classifier layers](usage-classifier-layers.svg), [confidence](usage-classifier-confidence.svg) | Deterministic classifier examples and constants; inferred categories/confidence are not runtime model-quality scores. |

The current detailed contracts are in [Transcripts](../TRANSCRIPTS.md) and
[Usage metrics](../USAGE-SCORECARD-METRICS.md). Source-based corrections to active diagram labels
must preserve this distinction; historical HTML design content is not rewritten as current fact.
