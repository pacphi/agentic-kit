One taxonomy, three presentations

  • System / Machine → resource type → resource → installation
  • User → resource type → resource → installation & available hosts
  • Projects → repository → resource type → resource → installation
  • Plugin → included skills; skill → “Provided by” relationship
  • Selection → consumers, dependencies, overrides, and other installations

Counts mean distinct installations, never a sum of repeated relationship links. “Provided by” requires recorded evidence. Examples here are fictional.
